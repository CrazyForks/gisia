# Release of 1.5.1

## What's new

1. Update Rails to 8.0.5.1 to fix an Active Storage arbitrary file read and remote code execution vulnerability
2. Update node-tar to 7.5.22 to fix a decompression denial of service vulnerability

## Actions

1. Change the gisia version to `image: gisia/gisia:1.5.1` in your `docker-compose.yml`
2. Run `docker compose up -d` to update the web service
